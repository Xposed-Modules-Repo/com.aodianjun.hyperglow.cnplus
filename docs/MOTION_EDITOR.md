# Motion 编排器使用说明

Word Effect Studio 的「Motion 编排」页：歌词 → 时间 → 生成器/手动排版 → 贴纸 → 导出。
本文覆盖当前版本（脚本 v22，预算 1024 指令 / 128 常量 / 16 KiB 估算）。

---

## 1. 界面与尺寸

- 三栏：左「歌词 / 音乐与时间 / 行与镜头」、中「预览 + 手动排版」、右「编排 / 导出」。
- 顶栏跳转：**歌词 / 预览 / 手动 / 编排 / 导出**，点击直接滚到对应卡片（可跨栏滚动）。
- ≥1181px：三栏各自滚动，页面高度约等于视口；1280 级收窄左右栏给预览留宽度。
- ≤1180px：两栏；≤980px：单栏；滑杆自动换行，窄屏无横向溢出。

## 2. 歌词与时间

- 语法：`/` 分镜、`*强调*`、行末 `!` 闪光、`歌词|注音`、`[mm:ss.xx]` 时间戳、
  `[间奏 8]`、`#` 注释、空行停顿。
- 时间优先级：点击同步（空格打点 / 退格撤销）> LRC 时间戳 > BPM 铺底；可开拍点吸附。
- 「行与镜头」列表可直接改行时间、点 ◎ 跳转。

## 3. 生成器

- 14 个预设：抒情慢歌 / AMLL 大字卡点 / 逐词瀑布 / 打字机 / 和风摇曳 / 热血全开 /
  星空闪烁 / 极简纯净 / 对焦呼吸 / 手绘圈注 / 金色星火 / 星芒爆闪 / 线条留白 / 画报侧栏。
- 主题 + seed 决定随机参数，同 seed 逐字节复现；任一滑杆改动回落「自定义」。
- 构图：自动轮换 / 横排 / 竖排 / 错落 / 散点 / **线条留白** / **画报侧栏**。
- 图形：自动轮换 / 无 / 下划线 / 框线 / 印章圈 / 行底辉光 / **画报侧栏**。
- 效果层（可独立开关）：
  - 对焦呼吸：四向淡重影 + shadowLayer 柔边，远处词变虚变暗；
  - 手绘圈：当前演唱词外一道带缺口弧，随词进度描出并淡出；
  - 金色余火：每词两粒暖色余烬 + 行底辉光；
  - 星芒爆闪：12 颗内置四角星贴图爆闪/微闪；
  - 手绘线条：每词弧线 + 每 3 词短横线。
- 启用任一效果层时自动改用单一手法，节省指令预算。

## 4. 手动排版（逐词自由度）

1. 勾选「启用手动排版」——生成器的构图/手法/装饰全部让位；
2. 「行」下拉选一句歌词（自动跳到该行预览）；
3. 画布上**直接拖词**改位置；拖空白处平移整行；
4. 点词后用滑杆精调：位移 X/Y（em）、缩放 0.3–3、旋转 ±180°、透明度 0–1；
5. 每行独立保存；「重置该词 / 该行 / 清空全部手动」随时回退。

实现：覆盖按「整行文本 + 词号」写入 `program.wordOverrides`（≤256 条，纯数值 + 行文本），
程序用 `wordOverride` 指令查表，未命中回落视觉行号键、再未命中返回恒等值；表项不占指令数，
按 `48 + 行文本长度` 字节计入 16 KiB 估算。工程 JSON 保存/恢复全部覆盖。
**旧版 App 不认识该指令，需要新版 APK。** 字段/指令/预算的完整定义见
[`WORD_EFFECT_PROGRAM_API.md`](WORD_EFFECT_PROGRAM_API.md)。

## 5. 贴纸与自定义图片

- 内置素材 0–15：星 / 四角星 / 圆环 / 三点 / 胶带 / 波浪 / 箭头 / 心 / 音符 / 月牙 /
  角框 / 点阵 / 半调 / 下划线 / 斜杠 / 标签框。
- 自定义图片：App「外观 → 自定义贴纸」导入，得到编号 64–255；编辑器填同编号即可引用。
- 网页「导入本机图片（仅预览）」：本地图片缩到 256px 存在工程 JSON，**不进效果包**；
  实机仍需在 App 导入同一张图。编号是设备本地分配的，换机/重装需重新对应。
- 贴纸操作：画布拖动、X/Y/宽/高/旋转/透明度滑杆、选中金色虚线框、最多 6 张，
  画在文字之前（背景层）。
- 贴纸动画（每张独立）：
  - 静止 / 漂浮（正弦位移）/ 呼吸（缩放脉动）/ 旋转（连续，速度=度/秒）/
    明暗（透明度起伏）/ 入场弹出（开头约 0.5 秒由小到正常）。
  - 幅度、速度可调；动画按 `globalField time` 计算，导出后实机同源。
  - 动画从整首开始计时；「入场弹出」只在开头出现一次。

## 6. 预算与导出

| 项目 | 上限 |
| --- | --- |
| 指令数 | 1024 |
| 常量数 | 128 |
| 估算字节 | 16 KiB |
| 单帧绘制/测量 | 4096 |
| 盒数/路径/文字盒 | 512 / 4096 总点 / 512 字符 |
| 单词效果包文件 | 64 KiB |

- 统计栏实时显示用量；超限会给出具体原因。
- 导出用**紧凑 JSON**（缩进格式的 1024 条程序会超过 64 KiB 包上限）。
- 「加入当前效果包」把效果放进左侧列表；整包超过 64 KiB 时导入会被拒，建议只导出当前
  Motion 效果或删减旧效果。
- 包内程序是通用的：不绑定具体歌词，任何歌都按所选预设/顺序显示。

## 7. 兼容性

- 手动排版（`wordOverride`）与超过 512 条指令的程序需要**新版 APK**；旧版会判非法。
- 自定义贴纸编号 64–255 依赖 App 侧导入的同一张图；网页只能显示本机预览图或虚线占位。
- 字体、注音、翻译行由宿主绘制；效果程序只拿得到主行词表。

## 8. 快捷键与交互

- 空格：同步模式下打点（先勾选「同步模式」）；退格：撤销一次打点；R：随机编排；
- 画布拖动：手动模式下拖词改位移、拖空白平移整行；缩放/旋转用滑杆；
- 顶栏跳转：歌词 / 预览 / 手动 / 编排 / 导出。
