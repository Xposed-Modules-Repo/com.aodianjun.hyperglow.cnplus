歌词

语法说明
  • 一行就是一句;空行留出停顿
  • 我还记得/黎明的颜色 — / 标记镜头切分(记录用)
  • *黎明* — 强调段(行内含强调 → 该行编排幅度加成)
  • 行末 ! — 闪光(行开始瞬间全亮脉冲)
  • 歌词|注音 — 注音/备注(HyperGlow 的注音由宿主绘制)
  • [01:23.45]歌词 — 直接使用 LRC 时间戳
  • [间奏 8] — 8 秒间奏(省略秒数 = 4 秒)
  • # 开头 — 注释

音乐与时间

行时长填 0 = 每行 4 拍(BPM 决定)。LRC 时间戳与点击同步优先于 BPM 铺底。
同步模式下跟着音乐,在每行开始的瞬间按空格打点;按错了用退格撤销。
