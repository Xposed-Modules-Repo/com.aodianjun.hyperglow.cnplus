歌词

      
      

      

        AI 切词(可选):自动按语义切行、标镜头/强调/闪光
        

          
        

        

          
          
        

        

          
          
        

        
OpenAI 兼容接口即可;密钥只存在本浏览器 localStorage,浏览器直调接口(接口需允许跨域)。结果回填歌词框,可手动微调。

      

      

        语法说明
        
    
          
  • 一行就是一句;空行留出停顿
    • 
          
  • 我还记得/黎明的颜色 — / 标记镜头切分(记录用)
    • 
          
  • *黎明* — 强调段(行内含强调 → 该行编排幅度加成)
    • 
          
  • 行末 ! — 闪光(行开始瞬间全亮脉冲)
    • 
          
  • 歌词|注音 — 注音/备注(HyperGlow 的注音由宿主绘制)
    • 
          
  • [01:23.45]歌词 — 直接使用 LRC 时间戳
    • 
          
  • [间奏 8] — 8 秒间奏(省略秒数 = 4 秒)
    • 
          
  • # 开头 — 注释
    •

        预览与实机共用同一 VM,所见即所得;字体/注音由宿主绘制,以实机为准。
        导出的程序是通用的:不绑定具体歌词,任何歌都按当前预设与顺序编排显示。歌词只用于预览与 AI 切词。
