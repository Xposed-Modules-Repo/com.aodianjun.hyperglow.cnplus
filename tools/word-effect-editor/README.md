# Word Effect Studio

HyperGlow 单词效果包的浏览器编辑器：写声明式轨道（`tracks` / `colors`）、写沙箱字节码程序
（`program`）、实时预览、导入导出 `.hgwordanim.json`。

规格以仓库文档为准：[`docs/WORD_EFFECT_PACKS.md`](../../docs/WORD_EFFECT_PACKS.md)。编辑器里的
规范化、缓动、求值与 VM 都按 `WordEffectModels.kt` / `EffectProgram.kt` / `EffectRuntime.kt`
逐值对齐，并用仓库自带的两个样例包做回归测试。

## 打开

不需要构建、没有依赖，直接用浏览器打开 `index.html` 即可。

如果浏览器限制 `file://` 下的脚本（少数环境），在目录里起一个静态服务器：

```bash
python -m http.server 8799 --bind 127.0.0.1
# http://127.0.0.1:8799/index.html
```

## 部署到 GitHub Pages

编辑器是纯静态页面，GitHub Pages 可以直接托管：

- **单独仓库**：把 `index.html` / `engine.js` / `templates.js` / `app.js` 放到仓库根目录，
  Settings → Pages → Deploy from a branch → `main` / `(root)`。
- **现有仓库**：仓库已带 `.github/workflows/pages-word-effect-editor.yml`，Pages Source 选
  **GitHub Actions** 后推 `main` 即可；工作流只发布六个站点文件。
- 生成干净目录：`python tools/word-effect-editor/make_site.py --out build/word-effect-studio`。

完整步骤和注意事项见 [DEPLOY_GITHUB_PAGES.md](DEPLOY_GITHUB_PAGES.md)。

## 界面

- **左栏**：效果列表。`+ DSL` 新建声明式效果，`+ 程序` 新建字节码效果；悬停条目可复制 / 删除；
  下方的模板下拉可以直接从 10 个内置 DSL 模板新建（含打字机 / 霓虹 / 震动 / 聚焦）。
- **中间**：实时预览。示例歌词可改；CJK 按字切块、英文按词切块；播放 / 暂停（空格）、速度、
  循环、拖动进度条。HUD 显示当前词的 `p`（词进度）与 `t`（stagger 后的时间轴），这是写关键帧
  时最需要的两个数。展开「词时间轴」可以看到每个词的开始时间、时长和长 / 短标记，点击任意行
  直接跳到该词；「LRC 时间轴」可以把真实 LRC 行时间导入预览。预览行数（1–6）、画布高、
  字体（无衬线 / 衬线 / 等宽）和背景色都可调。
- **右栏**：检查器。DSL 效果是标识、时间与粒度、辉光、数值轨道、颜色轨道、程序档、校验；
  程序档效果则是标识、程序档、程序上下文、可折叠的「DSL 备份」、校验——程序编辑器就在
  标识下面，不会被 DSL 控件挤到最底部。
- **底部抽屉**：`JSON / 校验`。规范化 JSON、逐条错误 / 警告、文件大小（64 KiB 上限）、
  紧凑导出；右上「编辑」可以直接改工作区的原始 JSON 并应用。

### 面板尺寸

- 左栏、右栏、JSON 抽屉、预览画布都有分隔条，直接拖动即可：左栏 180–420px、右栏
  320–640px、抽屉 200–600px、画布 260–720px。
- 尺寸会存到 `localStorage`，刷新 / 重开保持。
- 手机 / 窄屏（<980px）：三栏纵向堆叠，顶部栏自动换行，左右分隔条隐藏；JSON 抽屉变为
  底部浮层（72vh），画布分隔条加宽到 12px 方便触屏拖动，手机上不显示键盘快捷键提示。
- 「自动适配」默认开启：中间变窄时自动缩小预览字号，避免歌词被裁切；关掉则严格使用「字号」
  滑块的值（窄舞台可能裁切）。

### 关键帧曲线

每条数值轨道有一张曲线图：

- 点击空白处加一个关键帧（at = 横轴，value = 纵轴）；
- 拖动圆点改 at / value；首尾两个端点会被钉在 0 / 1（导出时规范化也会拉伸端点）；
- 右键圆点删除；每条轨道至少保留一个关键帧。

关键帧的 `at` 是**词进度** `p ∈ [0,1]`，不是秒数。`easing` 作用于本帧到下一帧这一段。

### 程序档

程序档是一个文本框汇编器。语法：

```text
; 注释（; 或 // 或行首 #）
label:                    跳转目标
push 0.5                  数字常量（自动进常量池）
push "text"               字符串常量
push true                 布尔常量
const 3                   显式常量下标（高级）
loadLocal 0 / storeLocal 1
lineField progress        globalField time / canvasField height / ...
wordField baseline        colorField sung / lineAtField width / ...
jump label / jz label / jnz label
add / mul / sin / clamp / drawText / save / restore / end
```

汇编是自动的：输入后 320ms 汇编。汇编器会做与 `EffectProgram.kt` 相同的 op / 字段 /
下标 / 常量预算校验，并沿所有跳转路径做静态栈深检查。汇编失败时保留上一次成功汇编的程序用于
预览，并在状态栏列出错误行号；点「反汇编当前程序」可以把已有 JSON 程序还原成可编辑源码。
模板下拉里有十个可运行的例子：最小示例、最小逐词循环、逐词弹跳、逐词旋转、整块波浪、
整块渐变 + 扫光带、粒子、辉光文字（用 `setShadow` / `clearShadow` 画辉光）、逐字点亮
（按字符细分：已唱字常亮，正在唱的那个字发光；英文逐字母、中文逐字）、邻字联动
（当前唱字带动同一行左右邻字，按字符距离衰减辉光与缩放）。

「调试当前帧」会以当前播放位置跑一帧并记录逐指令追踪：步数、绘制数、最大栈深、局部槽快照，
以及前 120 条指令（pc、源行号、op、参数、执行前栈深）。追踪最多记录 500 条，超出的部分会
标注截断。改动程序源后调试结果会清空。

程序里如果出现 `globalField baseline`，程序区顶部会提示「多行基线」：多行歌词会把后面的行
叠到首行。可点「修正多行基线」把缩放枢轴和 `drawText` 的基线都换成 `wordField baseline`
（官方早期单行示例 `program_bounce` / `program_spin` 可一键修）；也可以手动改或撤销。

新手向：

- 编辑器带行号；汇编错误列表里的「第 N 行」点一下会选中对应行并滚动过去。
- 「新手说明」折叠面板里有最小逐词循环、常用字段和指令入口。
- 模板下拉带一句说明，「用此模板替换」可一键换程序（可撤销）；当前程序与某个模板一致时
  会自动选中该模板。
- 成功状态显示「可以运行」，后面才是指令/常量/绘制/槽位/字节数等技术数字。

### LRC 时间轴

把 LRC 粘进「LRC 时间轴」文本框，点「解析」，选起始行和行数，再点「应用片段」：

- 支持 `[mm:ss.xx]` / `[mm:ss:xxx]` / `[mm:ss]`、一行多时间标签、`[offset:±ms]`，以及增强
  LRC 的 `<mm:ss.xx>` 字标签（字标签只从文本里剥掉，仍按行时间窗分配词时长）。
- 应用后预览时间轴从选中第一行的 0 开始计，词时间轴表会显示真实开始时间与时长，并标上
  `· LRC`；「恢复自动时长」保留当前歌词文本、回到按字符权重估算的时长。
- 最后一行如果后面还有未选中的歌词，会用它作为该行结束时间；没有就按字符权重估一个。

### 辉光

检查器新增「辉光」区：

- **策略**：`none` / `long` / `all`，与效果包规范一致。
- **预设**：常亮、呼吸、仅正在唱、长音节脉冲、渐入、闪烁、关闭。预设会替换现有的
  `glowAlpha` / `glowRadius` 轨道（关闭只把策略设为 `none`，保留轨道）；「长音节脉冲」
  会写成两条 `longOnly` 轨道；「仅正在唱」把 `glowAlpha` 两端压到 0，只有 `0 < p < 1`
  的词会亮——也就是辉光只跟着当前正在唱的词走。它会把 `stagger` 设为 0，让窗口严格对齐
  每个词自己的 `p`；需要错位波浪可以手动调回 stagger，但辉光窗口会跟着错位。
  点预设后按钮会保持选中态，面板显示「当前预设」；手动改辉光轨道会变成「自定义」，
  把策略设为 `none` 会显示「关闭」。
- **双样本预览条**：左边「长音节」、右边「短音节」，用当前播放位置求值，直接看出 `long`
  策略只点亮哪一边；下方读数显示当前词的半径 / alpha、未开始/正在唱/已唱完，或「不触发」
  的原因。
- **更细的「正在唱」**：DSL 的「仅正在唱」是整词级；要细到字符，用程序模板「逐字点亮」——
  它把每个词按 `stringLength` / `charAt` / `measureText` 拆成字符，已唱字常亮、未唱字暗，
  只有当前正在唱的那个字发光（英文逐字母、中文逐字）。
- **左右邻字联动**：程序模板「邻字联动」在逐字基础上按全局字符序号找到当前唱字，同一行内
  左右 1～2 个邻字按距离衰减辉光和缩放（1 / 0.67 / 0.33，3 个字外归零）；英文跨单词、
  中文跨字都联动，跨行不联动。全程只用文档里的 `wordCount` / `word` / `wordField` /
  `stringLength` / `charAt` / `measureText` / `setShadow` / `translate` / `scale` 等原语。
- **表面辉光 / 辉光色**：预览开关和调色板颜色，与示例卡里的「表面辉光」「辉光」同步。
- 词时间轴表新增「辉光」列，会亮的词显示一个小圆点；切换 `glow` 或阈值时实时更新。

### 原始 JSON

抽屉右上「编辑」把工作区 JSON 变成可编辑文本。应用会替换当前整包（包括非法条目，校验面板会
逐条列出），编辑期间自动刷新暂停；「格式化」只做 JSON 缩进整理。想追加而不是替换时，用顶部
导入按钮旁的「替换 / 追加」选择追加。

### 预览自由度

- 行数 1–6、画布高 260–560、字体（无衬线 / 衬线 / 等宽）、背景色都可调。
- 「表面」预设会重置调色板和背景色；之后可以再单独改背景色或四个调色板颜色。
- 这些只影响预览，不会写进效果包。

> 多行块请用 `wordField baseline` 绘制每个词。官方早期的 `program_bounce` / `program_spin`
> 是按单行写的，使用 `globalField baseline`，换行后第二行会被画到首行基线上——这是样例本身的
> 行为，编辑器会忠实复现。

## 导入 / 导出

- 导入只看内容，`.hgwordanim.json` 或任意 `.json` 都行；按条目校验，非法条目会列在抽屉里。
- 顶部「替换 / 追加」控制导入方式：追加会给重复 id 自动改名，把效果直接加进当前包。
- 导出写规范化后的整包（默认缩进格式）。如果缩进格式超过 64 KiB，会提示用「紧凑导出」；
  有结构错误时会拦下导出，可选择「紧凑导出」跳过非法条目。
- 「复制」复制规范化 JSON；`Ctrl+S` 直接导出。
- 工作区自动存到 `localStorage`，刷新不丢。

## Motion 编排(歌词动态排版)

主编辑器内置工作区(顶栏 **Motion 编排** 按钮切换,与编辑器同页,不再单独开页),
参考 [JIZURA](https://github.com/852wa/JIZURA)(MIT)的创作流,
把「整首歌的动态排版」一次性编排成**一个 HyperGlow 盒模式效果**。

流程:**写歌词(JIZURA 式轻量语法)→ 对时间(BPM 铺底 / 点击同步 / LRC 时间戳)→
选主题摇一摇(seed 可复现)→ 导出效果包**。

- **歌词语法**(与 JIZURA 对齐的子集):`/` 镜头切分、`*强调*`、行末 `!` 闪光、
  `歌词|注音`、`[mm:ss.xx]` LRC 时间戳、`[间奏 8]`、`#` 注释、空行停顿。
- **时间**:优先级为点击同步(Space 打点 / 退格撤销)> LRC 时间戳 > BPM 铺底;可选拍点
  吸附;行列表可直接改行时间与跳转。
- **编排**:四个参数化手法(绕词中心旋转的正弦波浪 / 弹跳 / 级联滑入 / 强调脉冲)按
  「(行号+词序) mod 轮换周期」分配;**14 个调优预设**一键套用,同预设同观感:
  抒情慢歌 / AMLL 大字卡点 / 逐词瀑布 / 打字机 / 和风摇曳 / 热血全开 / 星空闪烁 / 极简纯净 /
  对焦呼吸 / 手绘圈注 / 金色星火 / 星芒爆闪 / 线条留白 / 画报侧栏。
  主题与 seed 决定随机编排的全部参数,相同 seed 逐字节复现;滑杆可覆盖任一参数(覆盖后预设回落「自定义」)。
- **新增效果层**(程序内确定性绘制,不扩 VM 指令集):
  - 对焦呼吸:每词四向淡重影,焦点随行进度在词序列上滑动,远处更虚;
  - 手绘圈:当前演唱词外一道带缺口的弧,随词进度描出并淡出;
  - 金色星火/星芒爆闪:暖色余烬圆点+行底辉光,或 12 颗内置四角星贴图的爆闪/微闪;
  - 手绘线条:每词随进度描出的弧线 + 每 3 词一条短横线(简易线条动画)。
  启用任一效果层时自动收敛为单一手法,确保不超引擎指令预算。
- **预览即实机**:预览直接跑与实机同一份 `EffectVm` 盒收集器,导出的程序与预览所见一致。
- **手动排版(逐词自由度)**:开启后忽略预设/构图/装饰,按「锚点 X/Y + 整体缩放/旋转」定位;
  选一行 → 点词 → 拖位移/缩放/旋转/透明度滑杆,覆盖以「行号+词号」写入程序的
  `wordOverrides` 查表(不占指令预算,最多 256 词,`wordOverride` 指令读取);
  支持重置该词/该行/全部,工程 JSON 一并保存。旧版 App 不认识该表,需要同步升级。
- **手动贴纸**:手动模式可叠加贴纸层——内置素材 0–15 直接选;App「自定义贴纸」导入的图片
  用 64–255。贴纸可画布拖动、调宽高/旋转/透明度,画在文字之前(背景层),最多 6 张。
- **贴纸动画**:每张贴纸可独立选漂浮/呼吸/旋转/明暗/入场弹出,并调幅度与速度;
  动画按程序时间计算,导出后在实机同样播放。
- **本机图片预览**:网页可导入一张本地图片只用于预览自定义贴纸(缩到 256px 存进工程 JSON),
  图片字节**不进效果包**;实机仍需在 App 导入同一张图并使用同编号。
- **图形装饰**:每行可挂 accent 图形——自动轮换(无/下划线/框线/印章圈)、强制指定,
  或行底辉光条、画报侧栏(竖线 + 短粗线 + 三点 + 歌词下点状虚线),画在文字之前随行渐显;
  盒渲染器原生支持矩形/圆/线/路径,新增图元零渲染改动。
- **排版构图**:每行构图可换——自动轮换(按行内容在横排/竖排/错落/散点间轮转,同曲稳定)、
  横排、竖排(整行收一列居中)、错落(大小交替+基线错位)、散点(确定性散布)、
  线条留白(≤7 词靠右竖排、长句左侧横排并自动缩宽)、
  画报侧栏(左侧浮动横排 + 句内按内容放大个别词 + 自动缩到侧栏左侧);
  构图与手法解耦,导出的程序依旧不绑定具体歌词。
- **通用显示**:导出的程序不绑定具体歌词——任何歌都按当前预设与「编排顺序」显示
  (轮换 / 固定顺序按行长 / 每歌随机按内容派发手法);歌词只用于预览与 AI 切词。
- **AI 切词**:歌词卡内置 AI 面板(OpenAI 兼容接口 + 模型 + 密钥,存在本浏览器),
  一键把原始歌词按语义切行、标镜头/强调/闪光,回填时间轴;可手动微调。
- **直接入包**:编排好点「加入当前效果包」,效果进左侧列表末尾,可继续微调后随整包导出;
  也可以导出效果包 JSON / LRC / 可回灌的工程 JSON。
- **预算护栏**:生成器保证落在 1024 指令 / 16 KiB 估算 / 4096 绘制每帧内,状态栏实时显示用量。

完整接口（程序字段、指令栈语义、wordOverrides、贴纸/动画公式、工程格式、预算与兼容性）见
`docs/WORD_EFFECT_PROGRAM_API.md`。

与 JIZURA 的差异(边界):不导出 MP4 / PNG 序列(HyperGlow 的目标是锁屏/AOD 实时渲染);
不做音频节拍检测(v1 用 BPM + 吸附);特效库收敛到四个手法公式而不是数百种部件;字体与
注音由 HyperGlow 宿主绘制。注音语法可解析,但只作为行备注记录。

## 预览与实机的差异

预览是给写效果用的近似，不是像素级模拟：

- 字体是系统字体，不是实机歌词字体；字宽/行高不同。
- 辉光用 Canvas2D `shadowBlur` 近似 Android `setShadowLayer`。
- 预览的示例时间轴按字符权重估算词时长（英文长词自然落入长音节），实机时间来自歌词源。
- 实机画布的帧级裁剪在启用自定义效果时会放宽；预览画布按卡片裁切。
- `unsungDim` 走实机的 `steadyTextAlpha` 台阶：`< 0.5` 时未唱亮度 56%，`≥ 0.5` 时 100%。
  这不是线性暗度，编辑器在滑杆旁直接显示实际亮度。
